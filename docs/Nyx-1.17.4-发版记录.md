- 版本：**1.17.4**

## 一、这一版想解决什么

1.17.3 之前，安装包没有签名，隐私模式的页面快照根本不落盘（断网就什么也读不到）。
这一版把这两件事补齐：**安装包自己签名**、**隐私模式的快照整条加密后单独存放**；
同时给了 agent 一个能撤销的设置接口，并把离线缓存的站点名单做成可搬走的。
另外还有一个「看起来全绿、其实没验新包」的真 bug，也是在这一版被打包时抓出来的。

## 三、逐项说明

### 1. 打包前查证书有效期（`eeabbb1`）

**问题**：证书过期以后照样能签，只是签出来的包在 Windows 眼里是「无效签名」。
验签那一步才报错，人会以为是自己操作错了。

**做法**：新增 `scripts/lib/cert-validity.js` 作为唯一判据，三条规则写死：

- 已过期 → 直接失败，并告诉你怎么重新生成（`node scripts/make-signing-cert.js --force`）；
- 读不到有效期 → 同样失败（「读不到就不算有效」）；
- 剩余 ≤ 30 天 → 放行但打警告。

`scripts/build-signed.js` 在打包前调用 `assertCertUsable()`；`--status` 现在会打印剩余天数。

顺手修了一个真 bug：Windows PowerShell 5.1 的 `Get-PfxCertificate` 没有 `-Password` 参数，
之前那段一直打印空的 `Thumbprint=` / `Subject=` 却不报错，改用 `X509Certificate2` 读 pfx。

### 2. 加密快照解不开时只清坏的（`95234d8`）

换了系统账户、系统密钥变了，之前存的加密快照就解不开。以前只有一个「全部清空」。
现在先逐条试着解一遍，只把解不开的丢掉，能解的留着。

### 3. agent 改设置支持撤销（`479e263`）

`settings` 动作带 `undo: true` 就回滚最近一次成功的修改。仍然要走：

统一动作通道 → 人工确认 → 动作留痕 → 也能被紧急停止拦住。

**没有**在设置界面加一个能绕开确认的「撤销」按钮——那等于给了一条旁路。
界面上只显示「上一次改了什么、怎么撤销」。

### 4. 缓存站点名单导入导出（`16a157b`）

导出格式 `kind: 'nyx-cache-sites'`、`version: 1`。刻意和 agent 站点名单（`nyx-agent-sites`）分开：
一个管「agent 能不能动这个站」，一个管「断网时要不要留正文」，共用一个 kind 会让人导错文件。

### 5. 验签挑包按版本号（`1c0f402`）

**这是这一版最值得说的一条**：1.17.4 打出来之后跑验签，报告里验的是 `Nyx-Setup-1.17.3.exe`，
21 项里一串 ✔——新包根本没验。

原因：`findArtifact()` 按 `[dist-sign, dist]` 的目录顺序取「第一个命中的目录里排最后的名字」，
`dist-sign` 里躺着上一次签的 1.17.3，于是永远先命中它。

修法：新增 `scripts/lib/pick-artifact.js`，跨目录收集所有安装包后按**版本号**挑，同版本再看修改时间；
`verify-release-gate.js` 加 4 项纯逻辑断言把这个行为钉住。

## 五、踩到的坑

1. **验签挑到旧包**（上面第 5 条）：断言全绿但验的是别人。教训是「挑包」这种小事也要有纯函数和断言。
2. **`edit` 的 old_string 选太宽**：连吃掉相邻的 `clearBtn.addEventListener(...)` 和一条 CSS 规则，
   两次都是靠读回文件才发现。大改前先读上下文，改完必须 `node --check` + 跑相关回归。
3. **断言数到自己注释里的调用点**：静态守卫用正则找「不许出现的写法」，我自己的注释里写了那个写法。
   修法是先剔掉 `//`、`*`、`/*` 开头的行再匹配（本仓库第三次踩，已固化成 `stripComments()`）。
4. **项数标签散在多处**：`verify-all.js` 的头部注释、STEPS 的 `items`、脚本自己的输出，
   改一项要三处一起改，漏一处就出现「说 16 项实际 20 项」。
5. **pwsh 读中文 JSON 会按 GBK 解码**：`Get-Content latest.json | ConvertFrom-Json` 报「传入的对象无效」，
   要用 node 读。

## 六、已知边界（必须说清）

1. **自签名不等于公信签名**：能证明「包是这把钥匙打的、发布后没被改过」，
   但不能免掉 SmartScreen 的「陌生发布者」提示；也不能证明「作者是谁」。
2. **自签名没有时间戳**：证书一过期，之前签的包在 Windows 眼里就一起失效了。
3. **隐私快照是「整条加密」，不是「零痕迹」**：文件确实落盘了（`private-cache.json`），
   只是内容是 `safeStorage` 密文、24 小时自动作废、上限 20 条；同账户同机器能解开。
   系统密钥不可用时一律不存，不会退化成明文。
4. **agent 只能改 7 个键**，隐私与安全相关的键（模式、出站方式、站点授权、接入模式、私密快照）
   锁死到「连问都不许改」；撤销同样要走人工确认，也能被紧急停止拦住。
5. **安装器 e2e 不在 `npm run verify` 里**：要管理员权限、会临时移动真实用户数据，
   所以它是发版门禁（`--with-installer-test`），不是日常回归。

## 七、升级方式

- 应用内：设置 → 关于 → 检查更新（差分下载，`latest.json` 里带分块清单）。
- 或直接下载 `Nyx-Setup-1.17.4.exe` 覆盖安装，用户数据（书签、历史、设置）保留。
- 回退：`updates-archive` 里保留 1.17.3 / 1.17.2 / 1.17.1；`dist\legacy` 里另有 1.16.0 / 1.17.1 / 1.17.2
  供跨版本升级实测使用。
