## 一、这一版想解决什么

1.17.8 只做了「看得见」的头三步（设置页太长、摘要被压住、进程分不清）。这一版把剩下九项做完，重点是三件事：

- **工具栏不再一排图标**：只留四个主路径，其余收进「更多」，按钮可以带小字。
- **agent 在干什么，一眼能看到**：工具栏多一盏三色灯，点开是能就地急停的窄面板。
- **第一次打开有引导**：主题、按钮密度、下载目录、隐私链路、起始页一次问完，也可以一步「全部默认」。

外加一次真正的性能体检（先量，再决定砍不砍）和两套新主题。

## 三、逐项为什么这么做

### A4 网络面板能钉住（`cb9c6c9`）

原来的 `#net-follow` 只是个复选框，勾上才在切标签时换数据；不勾就停在一个 `webContents` 上，用户看不出自己看的是哪个标签的记录。改成两态下拉（跟随当前标签 / 锁定这个标签），锁定的标签被关掉时**当场说清楚并改回跟随**，不安静地换数据。

顺手两个真修：记录上限 4000 → **500**（每标签最多几条与"总数/丢弃数如实交代"都写进注释）；`toolbox.disable()` 原来只 detach、**不清理 `collectors`**，意味着关掉工具箱后每个标签最多 500 条仍然常驻——现在关闭就是真关闭。

### A5 agent 状态灯（`3caaf33`）

三色：灰=没接入、金=已接入空闲、红=正在被驱动。**红灯只在动作真正执行时亮**（`execute` 阶段起 4 秒窗口），不是"接入过就一直红"。点开是个窄面板：状态、最近 5 条动作、就地急停、去设置——**面板里没有任何输入控件**，避免把"看一眼"变成"能操作"。

一条刻意保留的边界：**「审计不完整」不许挤进三色灯**。否则红色同时表示"正在被驱动"和"看不全"，两种完全不同的意思。

抓到并修掉的真 bug：`decideLamp` 原来写 `until > now - 窗口`，导致**过期的截止时间仍算"正在被驱动"**（灯永远红）。

### C2 / C1 先量再决定砍（`a89b90d`、`a682076`）

C2 量了两组：冷启动（spawn→可连 CDP / spawn→preload 就绪）与占用（1 标签 / 5 标签），体积单独量。结论写进 `docs/性能基线.md`，并写清「Working Set 会把共享页重复算」「体积≠占用」。

C1 **没有为了"做了优化"而假砍**：用户唯一批准的那条「把该扩展移出随包」，实测本来就没随包（`src/bundled-extensions` 不存在，asar 2296 条里没有它）。三种真要省就得付代价的方案（GeoIP 按需下载 −12 MB、代理内核按需 −58 MB、去 dxcompiler+swiftshader −30 MB）列进 `docs/体积与裁剪评估.md` 交了决定。

### B1 / B2 顶栏与反馈（`7c9da81`、`8500586`）

四个主路径：新建、下载、隐私、工具箱；截图、摘要、扩展、代理中心进「更多」。小字标签默认开（图标认不出来时一行小字比 tooltip 救急）。截图这条**先定落点再截图**（`showSaveDialogSync` 早于 `capturePage`），取消就什么都不生成。

B2 把清单点名的 AI 味来源删掉：按钮外发光、悬停上浮、主按钮常态辉光、危险红光。动效给两档（克制 150ms / 活泼 220ms），系统"减少动效"时压到 90ms 且**不改写用户偏好**。

### D2 首装引导（`3d2c039`）

只在**全新安装**弹（安装器写 `pending:true`），升级安装写 `pending:false`，开发运行没有标记也不弹。四张卡、六个控件，每项都有「先不定」，**没有「下一步」**，一步「全部默认」就能进主界面。

顺手补的安全登记：引导窗口复用外壳 preload，需要 `sandbox:false`（第 3 处）。**没有放宽断言**，而是把 `onboarding` 正式登记进 `src/core/security-switches.js` 的 `WINDOW_ROLES`，外壳防护基线 17 → 19 项，文档里写明"新增窗口必须同时改三处"。

### D1 接入说明（`694d334`）

按当前状态生成：端点（内置回环 + `x-nyx-token` + token 文件位置）、九个动作、会被拦的四种情况、出错先看哪、边界（只监听回环、外部模式审计不完整）。**没有端口就不编端口**，**不做全文预览**（含 token 路径与端口，容易被顺手截屏外传）。

### D3 奶白 / 海盐（`995e41e`）

两套主题只换配色、**零渐变**（清单明确禁止科技紫蓝渐变）。设置页拆出「主题与显示」分区，主题 / 动效 / 小字三项归一处。

验证过程中抓到三个静默失效：

1. 设置页 `init()` 里 `await` 一个**永不返回**的 IPC（`nyx:hardware:status` 的 PowerShell 探测），后续初始化静默不发生——折叠功能整块没跑，但没人报错。改成逐项 8 秒超时兜住（`settleInit`）。
2. `.sec-scroll` 是纵向 flex，卡片一铺开就被互相压扁（量出来高度 0）——补 `.sec-scroll > .info-card { flex: 0 0 auto; }`。
3. 删旧区块时少删一个 `</div>`，导致新分区成为「外观」的子节点——探针打出 `displayParent` 才发现。

对比度也是实算的：奶白的 `--text-faint` 第一次只有 2.87:1，海盐 2.96:1，都改到 ≥3.3:1。

### 回归基础设施（`164afa4`）

本机可用内存掉到 3 GB 上下时，启动 Electron 的脚本偶发 `CDP 调用超时：Runtime.enable`，**单跑必过**。处理办法是放大等待（15s → 60s）并在 `verify-all` 里失败后干净环境重试一次，**一条断言都没改**，且两次都红仍按「重试后仍失败」报。

## 五、坑（这一轮新踩的）

1. **设置页 `await` 一个永不返回的 IPC，等于整块初始化消失**——而且不报错。凡是"初始化里等一下外部"的地方都要有超时与"跳过它继续"的日志。
2. **`.sec-scroll` 是 flex 列**，卡片默认 `flex: 0 1 auto`，一铺开就互相压扁；量 `max-height` 有值、`getBoundingClientRect()` 是 0 时先看祖先链的 flex。
3. **`edit` 删整段 HTML 少一个 `</div>`**，不报错、界面也不明显错，只是下一个分区变成子节点。改完大段 HTML 要统计开闭或跑探针。
4. **浅色主题的浅灰字必须先算对比度**：奶白 `#8a9299` 只有 2.87:1、海盐 `#7f9099` 2.96:1，肉眼"看着还行"，实算不合格。
5. **发版构建要读工作区的 `package.json`**：我只用 blob 技巧把版本号写进 index（避开推送线的 license 改动），结果 `build-signed` 读到工作区仍是 1.17.8，**把 1.17.8 的包重打了一遍**（字节全变）。正确做法是工作区也改成新版本号，index 里只放"版本号那一行"的改动。已从留档还原 dist 里的 1.17.8，避免同名不同字节。

## 六、已知边界（如实写）

1. **字号档位没做**：清单 D3 里明确"属独立改造"，这一版只在设置页如实写了这一句，没有假装有。
2. **`nyx:hardware:status` 在本机永不返回**：已被 `settleInit` 兜住（设置页照常可用），但根因（PowerShell 探测）没治，下一轮值得单独处理。
3. **`AGENT_STOP_SHORTCUT_FAILED`**：`CommandOrControl+Alt+X` 在本机被别的程序占用，只在诊断里，界面不提示。工具栏急停按钮与 MCP 侧急停不受影响。
4. **锁定的标签被关掉会改回跟随**：这是刻意的，但意味着"锁定"不是永久的，界面会明说。
5. **计划任务在安装版里注册不了**（安装版没有 `scripts/`），仍是 `NOT_AVAILABLE`。
6. **引导只在全新安装出现**：升级安装不会补问，老用户看不到这一屏——这是刻意的（升级不该打断人）。
7. **`--nyx-host` 把站点名写进命令行**：本机其他进程能读到。它是"能不能分辨"和"隐私"之间的取舍，诊断页里写明了。

## 七、升级与回退

- 升级：Nyx 里点「检查更新」，或直接跑 `dist\Nyx-Setup-1.17.9.exe`（覆盖安装，配置与书签保留）。
- 回退：装回 `%APPDATA%\Nyx\updates-archive\1.17.8\Nyx-Setup-1.17.8.exe`。回退后 `ui-preferences.json` 里的新字段（`motionLevel` / `toolbarLabels` / 主题 `cream`/`sea`）会被旧版忽略，不会损坏配置。
- 发版本机若更新源里的 exe 被安装程序删掉，用 `node scripts/make-release.js --restore` 从留档回写。
