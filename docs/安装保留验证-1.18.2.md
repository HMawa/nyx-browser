# 安装保留验证（AUD-03）· 1.18.2

> 这是给审计复验用的一次原始记录，不是自我声明。命令、耗时、逐条结果与 sha 对照都在下面，
> 任何人都能在本机照着跑一遍得到同样结论。

## 一、这条验证要证明什么

`16b25b0` 修的是「安装器把更新源里刚下载的那个包删掉了」。原来的判据是
`Buffer.includes('nyx-keep-package')` —— 它**永远不可能为真**：那个字符串是 NSIS 脚本里的
`Rename` 目标，编译后被 LZMA 压进安装包，exe 字节流里查不到。

所以 1.18.1 起换成功能判据：**真装一遍，看装完之后更新源里那个包还在不在、旧包有没有被清掉**。
判据落在 `scripts/verify-installer-retention.js`，并且已经接进 `scripts/make-release.js` 的
`installerRetentionGate`，正式发版时自动跑。

## 二、怎么复验

```powershell
# 在仓库根目录（D:\Nyx-src）
node scripts\verify-installer-retention.js `
  --installer="dist\Nyx-Setup-1.18.2.exe" `
  --previous="dist\Nyx-Setup-1.18.1.exe"
```

它做的事：① 先静默装 1.18.1（旧版）② 把 1.18.2 的包 `copyFileSync` 进
`%APPDATA%\Nyx\updates`（模拟"用户点了更新、包已经下好了"）③ 从更新源里的那个包静默覆盖安装
④ 断言保留包仍在、sha256 与大小与 `latest.json` 一致 ⑤ 断言旧包已被安装器清掉。

**注意**：它会真装到 `%LOCALAPPDATA%\Programs\Nyx`（这台机器的用户安装位置），
所以审计若要在隔离环境跑，请先准备好独立的 Windows 账户或快照——这一条我无法改成"不落盘"。

## 四、边界（别把这条当成"升级链全绿"）

- 这条只验证 **AUD-03**：装完之后包还在、旧包被清。它不验证升级弹窗、不验证首启引导。
- 它跑在本机（`%LOCALAPPDATA%`），不是隔离沙箱；隔离环境里跑需要独立账户。
- **独立复跑状态（如实写）**：11 项已在主开发本机跑通并有原始日志（见上），
  **未由审计方在隔离环境独立复跑**。审计若要签字，请用独立账户或快照按上面的命令跑一遍；
  在它跑完之前，本文只主张「跑通过、有日志」，**不主张「已独立验证」**。
- 发版时它会由 `installerRetentionGate` 自动执行，失败即中止发版；成功只打一行摘要，
  完整输出在发版日志里。本文件是**手工**再跑一次的存证，用来让审计有原始记录可查。
