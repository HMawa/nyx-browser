### G（完成 `1b6711c`，标签休眠：后台闲置就释放内存，agent 在用的永不休眠）

- 现象（清单 G）：要求「离线/在线切换、页面休眠、降低占用」，并点名两个例外——被 agent
  驱动的 tab 不参与休眠、有活动 MCP 会话时保持唤醒。实测本仓库**一处都没有**：全树搜不到
  `setBackgroundThrottling`、休眠、`powerSaveBlocker` 任何落点（只有各模块自己的 `sleep(ms)`
  工具函数），后台标签的渲染进程一直占着内存。
- 改动：
  - 新增 `src/core/tab-lifecycle.js`（纯逻辑、零 Electron）：三态 `active/background/asleep`、
    `normalizeSleepAfter`（0 = 明确关闭休眠；脏值/负数回默认 30 分钟；正数 < 1000 抬到 1000）、
    `readSleepAfterFromEnv`（`NYX_TAB_SLEEP_MS`，只作验证旋钮）、`decideTabLifecycle`（判定顺序：
    激活 → agent 会话 → 单独排除 → agent 驱动保护期 → 关闭休眠 → 已睡 → 超阈值 → 未到阈值，
    每条都带中文原因）、`summarizeLifecycle`（「共 N 个标签 · 1 个在用 · 1 个已休眠 · …」）。
  - `src/core/tabs.js`：5 秒一次巡检（`unref`，不挡退出）；`sleepTab` 用
    `removeChildView + webContents.close()` 真释放渲染进程并记住地址，`wakeTab` 按原地址重建
    `WebContentsView`（重绑事件、重设窗口打开策略、重施工具箱粘性）；切走时记 `lastActiveAt`
    （闲置从切走那一刻算）；布局跳过睡着的标签；`navigate/reload/retryLoadError/activate` 都先唤醒，
    `navigate` 还把目标写进 `sleepUrl` 以免"先加载旧地址再跳"；设置页标 `noSleep`（本地页休眠只换来白屏）。
  - `src/main.js`：`readTabSleepAfterMs()` 读阈值并在启动日志里说清（阈值被环境变量改过会明说
    "仅用于验证"）；`touchAgentSession(record)` 在审计入口统一续命——agent 动作的
    `execute/result/observe` 记录会 `markAgentDriven` + 会话 60 秒内保持唤醒（下载这类旁观动作也算）。
  - 外壳：休眠标签淡显 + 悬停说明「已休眠（已释放内存，点一下按原地址重新加载）」。
- 验证：17 个脚本 414 项全绿。其中新增 `scripts/verify-tab-lifecycle.js`（15 项纯 Node）与
  `scripts/verify-tab-sleep.js`（10 项端到端，真实起实例、`NYX_TAB_SLEEP_MS=1200`、自带测试站点）；
  端到端实测 `{"asleep":true,"activeAsleep":false,"dimmed":1,"asleepCount":1}`、
  唤醒后 `{"asleep":false,"url":"…/g2","loading":false}` 且正文回来、
  agent 会话期间 `{"tabAsleep":false,"agentSessionActive":true}`。
- 测试侧踩到两个坑：① 本地接口鉴权头是 `x-nyx-token`，写成 `Authorization: Bearer` 只会得到
  401「Token 无效」，看起来像令牌读错；② 端口文件先落盘、服务后 listening，必须先等 `/health`。
- 诚实边界：休眠等于卸载页面，**未提交的输入与滚动位置会丢**；5 秒巡检意味着最晚晚 5 秒才睡；
  「降低占用」只做到"闲置标签不占内存"，没做离线/在线切换策略。

#### G 的后续（`9801414`）：断网时不改链路，只如实说是断网

- 现象（清单 G 的离线/在线部分）：整机断网时，普通模式会因「代理不可达」把链路改成直连——
  网络恢复后就变成「代理模式却在直连」，用户毫不知情；隐私模式则反复报「代理已断开」，
  把「没网」说成「代理坏了」。
- 改动：`link-guard` 新增 `offline` 动作，判定插在「已经是直连」之后、隐私/普通分支之前——
  `online === false` 时链路一律不动，只发 `NETWORK_OFFLINE`；新增 `src/core/network-state.js`
  给说法（隐私模式「保持代理、不会因此降级为直连」，普通模式「链路保持原样、不会被改成直连」，
  并按当前是代理还是直连链路换文案）；`main.js` 加 `onlineState()`（读不到按有网，避免把真
  故障掩盖成断网）+ `nyx:net:state`；外壳加常驻断网横幅（`role=status`），渲染层只按载荷

- 验证：`verify-network-state.js` **10 项**（有网/读不到/脏入参都不显示、两种模式的文案与承诺、

  `verify-link-guard.js` 12 → **14 项**；`verify-ui-polish.js` 新增 1 项端到端（横幅默认隐藏 →
