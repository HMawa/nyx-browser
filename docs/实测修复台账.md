## 待办细目

### C1 诊断页
- 现象：出问题只能猜，找不到日志。
- 页面内容：App 版本 / Electron+Chromium 版本 / 当前连接方式（代理 or 真实 IP）/ 代理状态 / 硬件加速策略与当前 GPU / 最近 20 条错误（时间+错误码+URL）/ 「导出诊断包」。
- 技术落点：新增 `src/core/diagnostics.js`（环形缓冲 + 落盘 + 脱敏导出 zip）；`main.js` 里所有 catch 与失败回调统一走 `diag.error()`；设置新增「诊断」分区。
- 验收：制造一次失败（如访问超时地址），诊断页 5 秒内可见该错误；导出包可被外人看懂。

### A4 失败页
- 现象：失败只在设置里显示，主界面空白无提示。
- 技术落点：`did-fail-load` / `did-fail-provisional-load` → 主界面内建失败页；错误码映射（DNS/超时/证书/代理不可达/HTTP 状态）；「重试」「查看详情 → 诊断页」。
- 验收：`http://10.255.255.1`（超时）、`https://this-domain-should-not-exist.invalid`（DNS）、`https://expired.badssl.com`（证书）三者提示**不同且正确**。

### A2 不静默降级
- 现象：开 clash 后刷新几次，全隐私模式自己变回直连（不稳定复现）。
- 技术落点：隐私模式一旦开启禁止静默降级；探测失败 → 前台提示「代理不可达，已暂停隐私模式」+ 日志 + 开关状态保持可见；状态机每次变化记录「触发原因 / 探测结果 / 时间」。
- 依赖：**必须先有 C1**，否则无法定论。

### A1 下载
- 现象：灰度/普通/暴力都下不了文件，前台零提示（原话「文件下载这一块儿全都报废了」）。
- 已掌握的关键事实（1.16.0 线实测）：`will-download` 里 `event.preventDefault()` 之后再异步 `setSavePath` = 下载被取消，`setSavePath` 抛 `DownloadItem used after being destroyed` 被空 catch 吞掉。**必须同步定落点**。
- 技术落点：同步 `setSavePath`（或 `showSaveDialogSync`）+ `item.on('updated'/'done')` → 下载栏（进度/速度/剩余/失败原因/落点/打开目录）+ `Ctrl+J` 历史；隐私模式下载改为明确提示而非静默拦。
- 验收：5 种场景（<1MB / 10MB / 500MB / 短链重定向 / 403-404）全部有明确结果。

### B4+B5 设置
- 现象：两个「设置」入口；设置是弹窗，来回切。
- 技术落点：设置改为主界面**标签页**，全局只留一个入口（齿轮 / 菜单指向同一处），工具箱里的网页设置并入。
- 验收：任意入口点开同一页；改配置不需要关窗。

### B1/B2/B3
- B1：首屏给品牌 + 地址/搜索框 + 4~5 个常用入口，不做广告导航页。
- B2：隐私开关加可见文字 + 状态色 + hover 说明（禁历史/禁缓存/走代理）。
- B3：设置里显式「连接方式：代理 / 真实 IP」，写明真实 IP 下哪些保护失效。

### A3/A5
- A3：先测 500MB 上下行耗时基线，再决定是否改流式；禁止无数据优化。
- A5：默认核显优先（`--force_low_power_gpu` 一类），设置可切独显，启动日志打印实际 GPU 适配器。

### C2/C3/C4
- C2：Electron 43.7.4 / Chromium 150 / Node 24 的 CVE 对照表 + 缓解/升级计划。
- C3：安全开关现值表（`contextIsolation` / `nodeIntegration` / `sandbox` / CSP / preload 暴露面）+ 一次注入拦截演示。
- C4：录屏/远控进程检测（最小版），检测到就禁止开全隐私；检测不到要提示「无法确认」，不假装安全。
