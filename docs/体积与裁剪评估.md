# 体积与裁剪评估（清单 C1）

> 结论先说：**这一版不该再裁**。安装包里的 121.3 MB 中，能动的地方要么是 Electron 本体，
> 要么一动就改变行为（代理内核、免 GPU 兜底、GeoIP 规则）。清单 C1 要的"无行为变化的裁剪"
> 在现有组成里已经做完了，再往下走就必须付功能代价——那要你来点头，不该我自己决定。

## 当前体积构成（`dist\win-unpacked`，合计 389.7 MB）

| 组件 | 大小 | 是什么 | 能不能无代价去掉 |
| --- | --- | --- | --- |
| `Nyx.exe` | 238.5 MB | Electron 本体（含 Chromium/V8/Node） | **不能**。换主版本才会变，这一版 45.3.2 已经是当前能用的最新线 |
| `resources\vendor\mihomo.exe` | 58.2 MB | 内置代理内核 | **不能**。去了就没有"隐私模式必须走代理"这条底线 |
| `resources\vendor\geoip.metadb` | 8.1 MB | 代理内核的 IP 归属库 | 只能改成按需下载 → **行为变化**（首启无规则） |
| `resources\vendor\geosite.dat` | 4.0 MB | 代理内核的站点分类库 | 同上 |
| `dxcompiler.dll` | 24.6 MB | D3D12 着色器编译（WebGPU / Dawn 用） | 去了部分 GPU 路径退化到软件渲染 → **行为变化** |
| `resources.pak` | 12.8 MB | Chromium 界面资源 | **不能** |
| `icudtl.dat` | 10.3 MB | 国际化数据 | **不能**（中文界面依赖它） |
| `resources\app.asar` | 9.9 MB | Nyx 自己的代码 + 两个运行时依赖 | 理论上能省 1–2 MB（见下） |
| `LICENSES.chromium.html` | 5.4 MB | Chromium 许可证全文 | **不能**（法律要求随包分发） |
| `vk_swiftshader.dll` | 5.2 MB | 无 GPU 时的软件 Vulkan 兜底 | 去了在无独显/驱动坏的机器上会黑屏 → **行为变化** |
| `d3dcompiler_47.dll` | 4.5 MB | D3D 老编译路径 | 同上，部分老显卡需要 |
| `ffmpeg.dll` | 3.0 MB | 音视频解码 | 去了视频页播不了 → **行为变化** |
| `locales\` | 仅 `zh-CN` / `en-US` | 界面语言包 | 已经裁过了（默认会带几十种） |

## 已经做过的"无行为变化"裁剪（本次核对，均已生效）

1. `build.electronLanguages = ["zh-CN", "en-US"]` —— 语言包从几十种压到 2 种。
2. `build.compression = "maximum"` —— 安装包走 LZMA 最大压缩（代价是打包慢，用户端解压慢一点）。
3. `build.files` 里 `!**/*.map`、`!**/node_modules/**/{test,__tests__,tests,example,examples,docs}/**` —— 源码映射与依赖自带测试不进包。
4. `asar: true` —— 2296 个文件封成一个归档，减少安装后的小文件数量（对磁盘占用有好处，对包体积几乎无影响）。

## 随包该扩展扩展：已经不在包里（核对结果）

清单 C1 里唯一批准"会改变行为"的裁剪是**把随包该扩展扩展移出随包、只留源码**。核对结果：

- `src/bundled-extensions/` **不存在**（`Test-Path` 为 False）。
- `dist/win-unpacked/resources/app.asar` 的 2296 个条目里**没有任何**课程助手文件（按 `course|helper` 过滤只命中 SDK 自己的 `helpers.js` 之类）。
- `%APPDATA%\Nyx\updates` 里那两个课程助手 zip 是**更新源里的可选扩展包**，不是安装包的一部分。

也就是说这项裁剪**当前树里已经是这个状态**，不需要再改代码；用户本地数据（该扩展）也从来没有随包上传过任何地方。

## 如果以后真要再省，需要你点头的三种做法

| 做法 | 能省 | 代价 |
| --- | --- | --- |
| GeoIP / geosite 改成首启按需下载 | 约 12 MB | 首启没有分流规则，必须先联网拉一次；离线装机的机器上代理规则为空 |
| 代理内核改成按需下载（只在需要时拉） | 约 58 MB | 隐私模式在没有内核时**根本无法启动代理**，只能挡在"用不了隐私模式"这一步；也破坏了"装上就能用"的承诺 |
| 去掉 `dxcompiler.dll` / `vk_swiftshader.dll` | 约 30 MB | 部分显卡上 WebGPU 与 GPU 合成失效，可能白屏/花屏；这类问题最难让用户自己判断 |

## 建议

1. **安装包体积不作为这一版的目标**：121.3 MB 对一个自带代理内核与完整 Chromium 的浏览器是正常量级。
2. 真正影响体验的是**内存占用**，不是磁盘体积：5 个标签 1086.7 MB。要省就省这里（休眠阈值、标签上限、后台节流），
   但那属于 G 项已经做过的方向，继续调它会改变"后台标签多久失效"的体验。
3. 若将来要动 GeoIP 按需下载，建议做成**设置里的可选项**（默认随包，允许用户选"精简模式"），而不是默认行为。
