# Nyx 1.0.10 内置开发者工具箱（交付记录）

- 交付日期：2026-09-21
- 版本：1.0.9 → **1.0.10**
- 起因：Edge 商店式扩展（猫抓等）在 Electron 31 内核上装不起来——MV3 service_worker 不注册、`contextMenus/action/declarativeNetRequest/sidePanel/scripting/webNavigation` 等 API 缺失、Nyx UA 无 `Edg/` 标识被商店页拒绝。结论是「扩展路线走不通，就把扩展干的事做进浏览器本体」。本版即该「水桶」工具箱。
- 涉及文件：`src\core\toolbox.js`（采集/详情/嗅探数据层）、`src\core\toolbox-devtools.js`（页面环境能力层）、`src\renderer\toolbox-ui.js`（面板 UI）、`src\preload-tab.js`（页面侧桥）、`src\main.js`（IPC 注册）

---

## 一、入口与形态

- 标题栏「工具箱」按钮开合面板；面板从右侧贴边，宽度分档、可拖动宽度，Esc 逐级关闭（先关详情，再关面板）。
- 三个页签：**网络抓包 / 资源嗅探 / 页面环境**。
- 抓包与嗅探共用同一份数据源（同一采集器、同一 `seq`），所以「抓包里有、嗅探里也一定有」，两页只是筛选视角不同。
- 全部判定（类型归类、可下载性、是否内联、能不能出 cURL）都在主进程做，面板只负责展示与收集参数，界面与主进程两份常量同源，避免错位。

## 二、网络抓包（对标 DevTools Network）

- 采集通道：CDP `Network.*`（按标签独立挂载，抓包记录按标签分开存）；标签切换后主动对账，通道掉线可点「重连」。
- 列表列：方法 / 状态 / 类型 / 地址 / 域名 / 大小 / 时间；状态、类型各有配色标记。
- 类型筛选胶囊（带实时计数，节流刷新）：全部 / 文档 / XHR / JS / CSS / 图片 / 媒体 / 字体 / WS / 失败 / 其他。
- 峰值保护：单个页签最多保留固定行数 DOM，超出的从最旧开始滚动丢弃，丢弃条数在面板上明示；主进程侧另有累计与丢弃计数。
- 暂停 / 继续 / 清空：暂停期间不再入表，清空后主进程与面板两侧同时归零。
- 请求详情（点行展开 42 项字段）：
  - 概览：方法、状态、类型、MIME、大小、耗时、协议、远端 IP、时间、完整地址
  - 请求头、响应头、请求载荷（GET 或空体有明确提示）
  - **响应正文预览**：文本类自动取正文
  - 操作：复制 URL、**复制 cURL**（可直接粘进终端）、下载、打开、在当前窗口新建标签打开
- 正文取数三段兜底（本版重点修复）：
  1. 记录完结时预取正文并缓存；
  2. 首取失败进「自动补取」队列，`BODY_RETRY_DELAYS = [1200ms, 4200ms]` 两轮延迟补取，期间详情页提示「正在自动补取」；
  3. 主文档（Document）原始响应体被内核释放、返回 `No resource with given identifier found` 时，**用当前页 DOM 序列化兜底**——按 `源+路径` 判定为同一页面即可用（页面常被前端改 query，如 Bing 自动补 `&first=1`，逐字比 URL 会误判跳过）。
- 主进程正文缓冲额度：单资源 16MB、总计 64MB。

### 实测（本机，来源页 `cn.bing.com/images/search`）
- 匹配 202 条 / 共记录 205 条；胶囊计数：文档 2、XHR 58、JS 60、CSS 9、图片 73、媒体 72、字体 0、WS 0、失败 1
- 详情 42 行、cURL 按钮在位、主文档正文预览出真实 HTML、暂停与清空均生效、控制台无报错

## 三、资源嗅探（对标猫抓）

- 分类：图片 / 音频 / 视频 / 字幕 / 流媒体 / 文档 / 其他；每条给「人能读的文件名」（取路径最后一段，去超长与 query）。
- 条目动作：复制资源地址、下载（走主进程写系统下载目录）、打开（交给系统默认程序 / 播放器）、跳到抓包页签看完整请求。
- `data:` 内联与内存资源单独标注「内联数据（mime）」，不给假路径，也不给下载按钮（没路径可截）。

## 四、页面环境（对标「检查元素 / 控制台 / 改样式」那套）

- **开发者模式**：一键打开原生 DevTools（停靠方式可选、跟随窗口），这是唯一完整的检查元素 / 控制台 / Sources 断点入口。与抓包互斥——DevTools 占用 CDP 通道时抓包自动暂停并明示原因，关掉 DevTools 后点一次重连即恢复。
- **元素拾取**：点哪抓哪，纯页面脚本注入（不依赖 CDP，DevTools 开着也能用）。拾取后回传选择器 / XPath / HTML，可复制 CSS 选择器、XPath、outerHTML、元素文本、盒子 / 文本信息，可在页面上高亮闪一下；60 秒不点自动超时，Esc 取消。
- **快捷取数**：对选择器执行一段脚本（表达式里的 `el` 即选中元素），返回 JSON 可序列化结果。
- **UA 伪装**：内核默认 / 桌面 Chrome / 安卓 Chrome / 微信内置浏览器 / 微博客户端 / 自定义（可带 `Edg/` 标识，用于只认 Edge 的站点）。带「粘性设置」，新建标签自动套用；部分站点需重载才切换，面板会提示。
- **设备视口**：桌面 1920 / 笔记本 1366 / 平板 / 移动，只改渲染尺寸与触摸能力、**不改 UA**，与 UA 可自由组合——这就是「一条链接换桌面网页 / 手机版网站」的开关。
- **网络限速**：不限速 / 快速 3G / 慢速 3G / 离线（断网），验证在线课堂、播放器在弱网下的表现。
- **禁用 / 恢复页面 JavaScript**。
- **截图**：可视区截图与整页截图（超出视口部分一并截），走 Electron 原生接口，不需要 CDP。
- **清理与取证**：清当前站点浏览数据（站点存储、磁盘缓存等）。
- **页面信息**：标题、地址、状态、视口、屏幕、语言、时区、Cookie 项数、本地存储键值、脚本 / 框架数、图片 / 表单数。

## 五、已知边界

1. **跨进程子框架（OOPIF）的请求正文取不到**——已确认与缓冲额度无关，属内核限制，列表与头信息正常。
2. **主文档正文是「渲染后 DOM」不是原始字节**——原始响应体被内核释放后无法再取，DOM 兜底能拿到实际页面结构，但拿不到原始响应文本（如服务端注释、原始 JSON 缩进）。要原始字节请在重新加载时于抓包页签直接看。
3. **DevTools 与抓包互斥**：同一 CDP 通道，DevTools 打开期间抓包让位，属设计取舍。
4. 面板宽度、限速等设置对新标签生效（粘性），个别站点需刷新才能体现。
