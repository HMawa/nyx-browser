## 1. 现象（动手前是什么样）

工具箱的「资源」页只能列出**网络真的请求过**的资源：

- CSS `background-image` / `border-image` 里的图，经常走浏览器内部请求，Network 里看不到；
- 内联 `<svg>` 根本没有 URL，一条请求都没有——但那往往就是页面上的 logo、图标；
- favicon 是浏览器自己按 `link[rel=icon]` 取的，多数时候不在 Network 视口里；
- `srcset` 只发当前这一张，其余候选看不到；
- 懒加载图在滚动前只有 `data-src`，没请求过。

所以「把这一页上看得见的图都存下来」用嗅探是做不到的，必须回 DOM 里数。

## 2. 取证

| 位置 | 事实 |
| --- | --- |
| `src/core/toolbox.js`（1–80 行） | 嗅探的数据源是 CDP `Network` 域，靠 `EXT_RULES` 与 MIME 判种类，只覆盖"请求过 + 认得出"的资源 |
| `src/main.js` 的 `downloadResource` | 只能下单个 `http(s)` 直链，落点是系统下载目录，不能让用户选目录 |
| `src/renderer/index.html` 的 CSP | `img-src 'self' data:` —— **远程图片直接写 `<img src>` 会被拦**，预览必须转成 data: URL |
| `src/main.js` 的 `initSiteIcons` | 已有 `electronNet.fetch` 的用法（走 Chromium 网络栈、跟随代理），预览取图沿用同一条链路 |

## 3. 改了什么

### 3.1 纯逻辑（新增 `src/core/media-collector.js`，零依赖）

| 函数 | 作用 |
| --- | --- |
| `buildCollectorScript()` | 返回一段可 `executeJavaScript` 的采集表达式：`<img>`（currentSrc/src/srcset 全候选）、懒加载属性（`data-src`/`data-original`/`data-lazy-src`/`data-actualsrc`/`data-echo`/`data-srcset`）、CSS 的 `backgroundImage`/`borderImageSource`/`maskImage`（扫最多 8000 个元素、只要可见面积 ≥ 4px²）、内联 `<svg>`（序列化成 data URL）、`link[rel~=icon]` 系列、`video` 的 `poster`/`src`/`<source>` |
| `normalizeCandidates(raw, baseUrl)` | 绝对化（只认 http/https，`data:` 只留 svg，`blob:` 标成 `ephemeral`）、按 URL 去重并保留面积最大的、定种类、起文件名、按种类与面积排序、截断到 400 条并报 `truncated` |
| `sanitizeFileStem()` / `extFromUrl()` | Windows 保留字符与保留名（CON/PRN/AUX/NUL/COM1-9/LPT1-9）、首尾点、超长截断到 80；扩展名能认出就用真的，认不出按种类兜底（不给 `.bin`） |
| `filterCandidates()` / `describeCandidates()` / `summarizeDownload()` | 种类与关键字筛选；「共 12 个：图片 8 / 站点图标 2 / 矢量图 2」；「已保存 9 个，失败 2 个：…」 |

### 3.2 主进程（`src/main.js`）

- `scanPageMedia()`：对活动标签 `executeJavaScript(buildCollectorScript())` → `normalizeCandidates(raw, wc.getURL())`，落一条诊断 `MEDIA_SCAN`（列出/总数/丢弃/截断）。
- `downloadSelectedMedia(payload)`：**先 `showSaveDialogSync` 选目录**（`openDirectory` + `createDirectory`），逐条 `uniqueSavePath` 取名 → 先 `pendingDownloadPaths.push` 再 `wc.downloadURL`（下载中心的配对靠这个顺序）→ 汇总 `{ok, dir, saved, failed[{url,reason}], summary}`；一批最多 120 条，超出的进 `failed` 并说明"剩下的请再点一次"。
- `loadMediaThumb(payload)`：预览取图。`data:image/svg+xml` 原样回；`http(s)` 走 `electronNet.fetch`（跟随代理），要求 `content-type` 是 `image/*`、≤ 2 MB、8 秒超时（`AbortController`），回 `data:...;base64,...`。
- 三条 IPC：`nyx:tb:media-scan` / `nyx:tb:media-save` / `nyx:tb:media-thumb`；`preload` 对应 `mediaScan()` / `mediaSave()` / `mediaThumb()`。

### 3.3 界面（`src/renderer/index.html` / `style.css` / `toolbox-ui.js`）

「资源」页顶部一块「本页媒体」：`扫描本页图片` / `全选` / `全不选` / `保存选中（N）`，下面是逐条清单（复选框 + 34px 缩略图 + 种类 + 文件名 + 尺寸 + 「页面内临时地址」标记），点缩略图在面板里看大图。

三处实现细节：

1. **缩略图懒加载**：`IntersectionObserver`（root 是列表、`rootMargin: 80px`）看到哪行取哪行，并发上限 3，一次扫描最多自动取 60 张——否则扫完 400 条就等于把整页图再下一次。
2. **勾选状态存在 `tb.mediaItems` 里**，不在 DOM 上：换筛选、重新渲染都不会丢勾选。
3. **重新扫描会作废旧预览**：清 `mediaThumbs` + 清队列 + 重置自动配额，并把仍在飞的旧回包按"状态对象已换"丢掉，避免旧图贴到新列表上。

16 项断言覆盖：

| 断言 | 守的是什么 |
| --- | --- |
| 采集脚本只读页面 | 不许出现 `fetch(`/`XMLHttpRequest`/`sendBeacon`/`localStorage`/`document.cookie`，也不许出现 `.value`/`innerHTML =`/`appendChild`（不读输入框、不改 DOM） |
| 地址补全与协议白名单 | `javascript:` / `mailto:` 不经白名单会被 `new URL` 解析成功，列出来就是骗用户点（**这条是真 bug，第一版漏了**） |
| 同一地址多次只留面积最大的 | 去重要可解释，不能"少了几条没人知道" |
| `data:` 只收矢量图 | 位图 data: 会把 IPC 载荷撑爆 |
| 文件名能落 Windows | 保留字符、保留名、超长、首尾点 |
| 超上限截断并报 `truncated` | 截断必须可见 |
| 三条通道 + 三个接口 + 四块元素 + `wireMedia()` | 接线漏一处就等于功能不存在 |
| 保存三约束 | 必弹目录选择框、隐私模式必拒绝、逐条必报原因 |
| 预览五约束 | 隐私模式不预览、有大小上限、有超时、只收 `image/*`、可中断 |

## 5. 能证明什么 / 不能证明什么

**能证明**：扫描覆盖 `<img>`/CSS 背景/内联 SVG/favicon/视频封面/懒加载属性；清单可勾选、可筛选、可去重；保存到用户选的目录且逐条有结果；预览不绕过代理（隐私模式直接拒绝）。

**不能证明**（如实说明）：

- **跨域 CSS 背景取不到**：`document.styleSheets` 里跨域样式表的规则读不到（同源策略），所以「别的域名的 CSS 里写的背景图」扫不出来。当前实现扫的是**计算后样式**，只覆盖"已经渲染出来的"背景图。
- **`blob:` 与 canvas 生成的图**只能"趁页面还在"保存，关掉页面就失效（清单里标了「页面内临时地址」）。
- **视频只列地址**，不下载流：HLS/DASH 分片需要专门的合并逻辑（不在本项范围）。
- **隐私模式不能预览也不能保存**（预览会另发请求、保存会落盘），这是刻意的。
- 一次最多列 400 条、一次最多保存 120 条——超出的部分会明说，不静默截断。

## 7. 踩到的坑

1. `javascript:void(0)` 这种伪协议 `new URL(...)` 能解析成功，第一版因此把它列进了清单——断言先红才补上协议白名单。
2. `data:` 与 `blob:` 的 `pathname` 是 base64 片段/uuid，直接当文件名会得到一串乱码（第一版生成的 `svg+xml;charset=utf-8,_svg_-03.svg` 就是这么来的），改成这两种协议不取 URL 主干、按种类起名。
3. 界面的 CSP 是 `img-src 'self' data:`：预览**必须**由主进程转 data URL，直接写远程地址会被静默拦掉（表现成"图裂了但没报错"）。
