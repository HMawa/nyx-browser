## 二、逐项说明

### 2.1 建议条目的站点图标

设计是「先给占位、再补真图」，任何情况下都不让列表等图标：

1. **首字母色块（同步、零网络）**：取域名首字母（中文/搜索行取「搜」），色相 = 域名哈希（同一站点永远同色），16×16 圆角块，尺寸与真图标一致，替换时不跳行。
2. **真图标（异步）**：主进程按 host 抓 `https://<host>/favicon.ico`：
   - 走 `electronNet.fetch`（Chromium 网络栈，跟随浏览器代理设置，与「出站链路受控」纪律一致）；
   - 2 秒超时、64KB 上限、按魔数嗅探图片类型（不信任 Content-Type）；
   - 落盘缓存 `<userData>/suggest-icons/<sha1(host)>.bin`，命中直接推；
   - 每次列表最多补 4 个 host，抓取失败的 host 本次运行内不再重试；
   - 拿到后通过 `nyx:as:icons` 推给浮层，浮层局部重渲染（保留当前高亮）。
3. **解码失败回退**：少数站点返回畸形 ICO，`<img>` error 时回退首字母色块，不留空白。

隐私：全隐私模式本来就不出建议（历史/书签痕迹不外显），因此**隐私模式下不会发生任何图标抓取**。

### 2.2 收藏到指定文件夹

- **触发**：长按星标 550ms（带 `.is-pressed` 按压反馈），或右键星标。普通点击仍然是「收藏 / 取消收藏」原语义——长按触发后会吞掉随后那次 click，不会误触发取消。
- **浮层**：独立无边框透明窗口 `bm-folder.html`（与书签浮层同款，DOM 浮层会被标签视图盖住），列出「书签栏」+ 各级文件夹（按层级缩进 + 子项计数）+ 分隔线 + 「新建文件夹并收藏…」。
- **选择**：鼠标点击或 ↑↓ + Enter；Esc 收起；失焦自动收起。
- **新建**：`新建文件夹 <日期>` 建在根下，然后把当前页收藏进去，日志与 `nyx:bm:changed` 推送保证书签栏 / 工具箱 / 星标三处同步。
- 窗口高度 = `28（头部）+ n×30（条目）+ 49（分隔线 9 + 新建行 30 + 面板内边距与边框 10）`，与 `bm-folder.css` 的高度契约一致。

### 2.4 一键回归 `npm run verify`

- 顺序执行三个 CDP 验证脚本（地址栏建议 37 项 / 界面体验 19 项 / 打包冒烟 7 项），单脚本失败不中断，最后汇总并以退出码表达结论。
- 每步前后按**可执行文件完整路径**清理本仓库遗留的 electron / 解包版进程（实测清掉 5 个残留），机器上安装版 `<安装目录>\Nyx.exe`（7 个进程）全程未受影响——这条是硬约束，写进了脚本注释。
- `dist\win-unpacked` 不存在时第 3 步标「跳过（请先 npm run dist:dir）」，跳过不计失败。
- 实测：`npm run verify` → **3 通过 / 0 失败 / 0 跳过，44s**。

### 2.5 升级下载加固

`src/core/updater.js`（465 → 638 行）：

- **断点续传**：下载写 `<文件>.part`；重启/重试时先看分片，带 `Range: bytes=<已有>-` 续传（206 追加；200 说明源不支持 Range → 从头覆盖；416 分片越界 → 丢弃分片全量重下）；日志打印「检测到未完成下载 x%，从断点续传」。
- **版本变化清理**：清单版本变了，旧分片直接删（避免把上一版数据拼进新包）。
- **流式 sha256**：`createReadStream` 1MB 分块喂 hash，不再 `readFileSync` 把 113MB 整包读进内存。
- **半截包防护**：响应字节数小于 Content-Length 判失败；sha256 校验失败连 `.part` 一起删。
- 实测（本地 HTTP 服务 + 5MB 假包，19 项断言）：掐断保留分片 → 续传 40% 起 → 校验通过；源不支持 Range 自动全量；416 自动降级；版本变化删旧分片。

### 2.6 差分更新：结论（不实现）

写进 `updater.js` 头部注释，要点：① 自研 Updater 未接 electron-updater，拿不到 blockmap 差分下载器；② 差分需要本地保留「上一版安装包本体」做块比对，而 `installer.nsh` 升级后会删掉 updates 里的 `*.exe`，天然缺基线；③ 未来路线是「`updates-archive` 留档保上一版 → 引入 blockmap 差分下载 → 更新源同时提供 `.blockmap`」；④ 在此之前「整包 + 断点续传 + 流式校验」性价比最高。

## 五、已知边界

1. 安装版仍为 1.2.9，本次只构建发布，未强装。
2. 图标只按 `https://<host>/favicon.ico` 抓取，不解析页面里的 `<link rel="icon">`（避免为图标去拉整页 HTML）；部分站点因此只有首字母色块。
3. 图标抓取会在建议出现时访问对应 host（走代理），失败不重试、2s 超时；隐私模式不发生抓取。
4. 收藏到文件夹只支持文件夹（无「收藏到子书签」），新建文件夹固定在根下且命名为 `新文件夹 <日期>`。
5. 长按时长 550ms 是经验值；触摸板用户可能更习惯右键（两条路都提供）。
6. 差分更新未实现（结论见 2.6）；当前更新仍是整包 + 断点续传。
