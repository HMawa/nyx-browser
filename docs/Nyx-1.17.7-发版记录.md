# Nyx 1.17.7 发版记录

> 发布于 2026-11-15。上一版 1.17.6（2026-11-15 凌晨）。
> 这一版把两个批次的九件事一起发出去：**B 前缀的那一批（第九轮）** 和 **第十轮的五项**。
> 一句话主题：**让「你看到的数字、状态、名单」都说得清它现在到底算不算数。**

---

## 1. 这一版想解决什么

1.17.6 之后连着做了两轮，都在补同一种毛病：**界面上写着的东西，和实际发生的事之间隔着一段没人说的话。**

- 差分报告写着「243 块 / 命中 0」，但那是**某一对包**的数字；更新源换了版本之后它照样挂在那儿，看着像在描述下一次更新。
- 设置页说「夜间 e2e：上次通过」，可这台机器上**计划任务根本没注册**——那句话是上周的结论。
- 模板能存了，但**换机器只能手敲**；套用只有「并进」一种，想换成另一套名单没办法。
- 「谁改得多」只数设置改动；agent 干了 200 次点击、被拦下 3 次，界面上一个字都没有。
- 隐私模式那份站点名单改了**却不生效**（快照关着、或系统加密不可用），界面照样说「已并入名单」。

这一版逐条把这些「没说出口的前提」搬到界面上，并且**每条都有断言钉住**。

## 3. 逐项说明（为什么这么做）

### 3.1 `2c726e2` 差分新鲜度：先问「这份数字还算不算数」

- **取证结论与直觉相反**：「重新量一次」这个按钮**第七轮就有了**，所以候选里的「加按钮」本身不成立。
  真正的缺陷是**静默过期**：`delta-report.json` 记的是某一对包的测量结果，更新源换版本之后旧数字照旧挂在卡片上。
- `src/core/delta-stats.js` 新增 `describeDeltaFreshness(report, {currentVersion, staleDays, now})`，五级：
  - `missing` 没量过；`failed` 上次没量成（带上当时的错误）；
  - `stale` **量的是 X → Y，而更新源现在是 Z** —— 直说「它不描述下一次更新」；
  - `aged` 超过 `STALE_DAYS = 30` 天；
  - `current` 说明是今天量的还是 N 天前量的。
- 判定**只在主进程与纯函数里做一处**，界面不再自己判一遍（`renderDeltaReport(report, freshness)`）。

### 3.2 `637de95` 夜间计划任务：能自己注册，也敢说有没有在跑

- 新增 `scripts/lib/nightly-plan.js`（参数拼法、输出解析、三态描述），`nightly-e2e.js` 增 `--register` / `--unregister` / `--status` / `--apply` / `--elevated`。
- 两个**真修**：
  - `schtasks` 的输出是 **GBK**。按 utf8 解，`错误: 系统找不到指定的文件。` 会变成一串「锟斤拷」式的乱码方框，「任务不存在」被误判成「读不出来」→ 一律 `encoding: 'buffer'` + `new TextDecoder('gbk')`。
  - 默认参数原来带 `/RL HIGHEST`（要管理员），第一次真注册直接「拒绝访问」。Nyx 是 `perMachine:false` 装到用户目录，**普通权限就够** → 默认不提权，要提权显式 `--elevated`。
- 状态文件多写一段 `scheduled`，设置页的状态卡里多一行「计划任务」。

### 3.3 `d49c9d9` 模板导出导入：能带走，也能被拦下

- `CACHE_TEMPLATE_EXPORT_KIND = 'nyx-cache-templates'`、`version: 2`，**不带 mode**（模板语义是「这些站点值得离线留」，mode 是用户当下的选择）。
- 导入三种拒绝说清原因：**版本更高**（「升级 Nyx 再导」）、**kind 不对**（「这是站点名单，不是模板——名单请用名单的导入按钮」）、**结构坏了**。

### 3.4 `b54940b` 动作聚合：被拦下的单独报数

- `aggregateAgentActions(records, {limit, since, until})`，两条口径：
  - **跳过 `settings`**：设置改动已经在那张表里数过了，两边都数会变成「一次改设置算两次动作」。
  - `deny` 或 `ok: false` **只计入 `denied`，不进执行次数**。混进去会把风险说小。
- 界面上是「动作 / 次数 / 最近一次 / 站点」四列 + 「主要在哪些站点」。

### 3.5 `9f5944c` 名单是否真生效：不说就等于骗人

- **取证结论**：一键套用自定义模板**第八轮就通了**。真缺陷是 `privateCacheDecision()` 依赖
  `privateSnapshotEnabled !== false` 与 `safeStorage.isEncryptionAvailable()`，
  两者任一不满足时名单**完全不生效，界面却说「已并入名单」**。
- 新增 `privateSiteEffective()` → `{enabled, encryptionAvailable, active, note}`，
  `nyx:offline:sites` / `-private-templates` / `-private-template-apply` 都带上它；
  不生效时把两句中文原因之一接在结果后面，并用警告样式显示。

### 3.6 `e8291d5` 计划任务改时间 / 删任务

- 把 `scripts/lib/nightly-plan.js` 的实现**搬到 `src/core/nightly-task.js`**，原文件改成一行转出口：
  主进程与命令行必须共用一份「参数怎么拼、输出怎么读」，两处各写一份迟早走样。
- 新增 `describeTaskAction(action, result, verify)`：**命令说成功但复核查不到，一律算失败**（注册与删除都复核）。
- `resolveTaskPaths({isPackaged, …})`：安装版里没有 `scripts/` → 明确回 `NOT_AVAILABLE` 并给出源码目录命令，不假装能管。
- **刻意不给「现在就跑一次」**：那是另一件事，且会在用户不知情时启动安装包。

### 3.7 `fd4c122` 模板「替换名单」+ 顺带套普通模式

- `applySiteTemplate(rawPolicy, key, extra, options)` 增 `switchMode`，**默认 merge**（向后兼容）。
- replace 时返回 `kept` / `dropped`，逐条报出被换掉的手写站点；**屏蔽名单原样保留**——
  那是"绝对不许"的一层，不该因为切模板就失效。
- `alsoNormal` 时对普通模式那份（`cacheSitePolicy()`）再套一次，**两份结果分开报**：一份失败不许影响另一份的结论。

### 3.8 `ac18009` 动作记录导出 CSV

- 表头 `动作,执行次数,最近一次,主要站点,被拦下或拒绝`；行尾 **CRLF**（旧版 Excel 不认裸 LF）。
- **被拦下总数只写在第一行**：一张表里每行重复同一个数只会让人以为它在按行动分。

## 5. 踩到的坑（都写进台账与 `AGENTS.md`）

1. **`git apply` 拆不出三桶**：`-U0` 没有上下文校验不了位置，`-U1` 的 new 侧行号假设所有桶都在。
   最终用 `temp/apply-r10.js`：`git diff --no-index --unified=1` + 按新增行关键词分桶 + **整段（含上下文）替换**，
   最后与备份逐 sha256 比对必须全部 `SAME`。
2. **改实现之后旧断言假红**：`delta: readDeltaReport()` 变成 `const delta = readDeltaReport()`；
   `applySiteTemplate` 加参数后旧正则照样通过（不锚定参数列表）。**改实现必须连断言一起改**。
3. **取数函数名字想当然**：普通模式那份站点名单叫 `cacheSitePolicy()`，**没有** `normalSitePolicy`。
4. **插 check 时吃掉了下一行**：把紧随其后的 `const failed = checks.filter(…)` 一起替换掉，
   跑出 `ReferenceError: failed is not defined`。改门禁脚本后必须立刻跑一次。
5. **`schtasks` 输出是 GBK**：中文报错按 utf8 解成乱码，导致「任务不存在」被判成「读不出来」。
6. **断言自己也会写错**：`/effective,$/` 少了 `m` 标志恒假——写完立刻跑。

## 6. 已知边界（不要当成「已经解决」）

1. **签名仍是自签名**：能证明「包是这里打的、打完没被改」，但**不是公信签名、没有时间戳**，SmartScreen 仍可能提示未知发布者。
2. **计划任务只能从源码目录注册**：安装版里没有 `scripts/`，界面会如实说 `NOT_AVAILABLE`。
3. **夜间 e2e 不会自己跑起来**：必须注册计划任务（设置页能改时间、能删），且那条链路依赖 `dist\legacy` 里有旧包。
4. **界面永远不提供「现在就跑一次」**：跑一次会在用户不知情时启动安装包。
5. **隐私快照不是零痕迹**：整条加密落盘、24 小时作废，不是"什么都没留下"。
6. **模板替换会让手写名单被换掉**：会逐条报出被换掉的站点，但**没有「先备份再换」**这一步。
7. **「它都干过什么」只统计留痕里的记录**：环形缓冲 1000 条 + JSONL 追加，超出窗口的早期动作不在表里。

## 7. 升级方式

- 应用内「设置 → 关于 → 检查更新」，或直接跑新安装包（`perMachine:false`，覆盖安装保留用户数据）。
- 回退：留档保留 1.17.7 / 1.17.6 / 1.17.5，`%APPDATA%\Nyx\updates-archive\<版本>` 里取旧包重装即可。
