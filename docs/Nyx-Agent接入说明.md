# Nyx · agent 接入说明（D1）

> 这是仓库里的**参考文档**。真正的接入说明由 Nyx 自己按当前状态生成：
> 设置 → Agent 访问 → 「接入说明」→「复制接入说明」或「保存为 .md」。
> 之所以不把端口、token 路径写死在这份文件里，是因为它们在不同机器、不同启动方式下都不同——
> 写死的结果一定是"照着文档填，连不上"。

---

## 1. 两种接入方式

| | 内置（推荐，默认） | 外部接入（CDP） |
| --- | --- | --- |
| 怎么连 | Nyx 自带 MCP 服务（stdio）→ 转发本地 HTTP 接口 | 别的程序直接连 Chromium 调试端口 |
| 动作通道 | 全部经过 Nyx 的统一动作通道（含站点授权、动作级确认、留痕） | 不经过，Nyx 看不见 |
| 审计覆盖 | **完整** | **不完整**（只看得到"经过浏览器的部分"） |
| 切换代价 | — | 需要重启 Nyx（调试端口只能启动时打开） |
| 端点 | `http://127.0.0.1:<端口>`（只监听回环） | `http://127.0.0.1:<调试端口>`（只监听回环） |

外部接入必须**两次确认**才能切换，其中第二步要勾选风险确认，且这是刻意做成"不能再关掉提示"的：
把审计变薄这件事不允许一键完成。

## 2. 内置模式的鉴权

每个请求都要带请求头 `x-nyx-token: <token>`。token 由 Nyx 生成并存在用户数据目录的
`api-token.txt` 里（设置页会显示具体路径）。不带或带错 → `401`，返回里会明确说"Token 无效"，
不会伪装成动作错误。

## 3. 能做什么

统一形状：`{ "type": "...", ...参数 }`

| 动作 | 说明 | 参数 |
| --- | --- | --- |
| `navigate` | 打开网址 | `url` |
| `readPage` | 读页面里的可交互元素 | 可选 `filter` |
| `screenshot` | 截当前页面 | — |
| `click` | 点中某个元素 | `elementId` |
| `type` | 往输入框里输文字 | `elementId`, `text` |
| `executeJS` | 在页面里执行一段脚本 | `script` |
| `extractText` | 取页面正文 | — |
| `state` | 看标签状态 | — |
| `settings` | 改设置（可选 `undo: true` 撤销上一步） | `key`, `value` |

`click` / `type` 要先 `readPage` 拿到 `elementId`，**不要猜 CSS 选择器**：页面刷新后旧 id 会失效，
猜出来的选择器在重排后会点错东西。

## 4. 会被拦下来的情况

1. **站点授权**：不在白名单的站点会先问用户一次；进了屏蔽名单的一律拒绝，**屏蔽优先于白名单**。
2. **动作级确认**：`type`（输入文字）与 `download`（下载）这类动作即使站点在白名单里也要再确认。
3. **锁死的设置键**：接入模式、隐私链路、隐私模式快照开关、agent 站点名单、下载是否询问、GPU 策略——
   agent 连"问"都不许问，只能由人在界面上改。
4. **急停**：被停止后所有动作直接拒绝，直到用户恢复。工具栏按钮与快捷键都能停。

## 5. 出错了先看哪

1. `401` → token 不对或没带请求头。
2. `403` / 被拒 → 看返回里的原因：站点被屏蔽、动作级确认没点、或 agent 已被急停。
3. "找不到元素" → 重新 `readPage` 拿新 `elementId`。
4. "什么都没发生" → 确认标签是不是在隐私模式（动作照常，但被拒绝会明确说原因）。

## 6. 边界（请如实转告使用者）

- 本地接口只监听 `127.0.0.1`，**不要做端口转发或反代**把它暴露出去。
- 外部接入模式下审计不完整是设计取舍，不是"暂时还没做"。
- 隐私模式不落盘；普通模式按设置保存历史与缓存。
- agent 改的设置可以在「Agent 访问 → 谁改得多」里看到，撤销同样要人工确认并留痕。
