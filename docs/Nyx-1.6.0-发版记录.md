## 二、逐项说明

### 2.1 按站点聚合折叠

- 候选打完分后按 host 分组：每组只露**分数最高的那条**，右侧给一枚 `+N` 徽标（N = 该站还有几条命中）；搜索行照旧排最后、且不参与聚合。
- 点 `+N` → 浮层调 `nyx:as:expand`，主进程用**同一份输入与锚点**重查一次（带 `expandedHost`），该站点的全部命中就地平铺；高亮会重置为"无"（等于一次新查询），再按 ↓ 即可选。
- 为什么折叠在主进程做：键盘导航的下标必须和渲染出来的行一一对应，折叠在渲染层做会让"第 N 条"对不上。

### 2.2 收藏到文件夹浮层支持搜索

- 顶部加搜索框，输入即时过滤（文件夹通常不多，不做防抖）；过滤只作用于文件夹行，「新建文件夹并收藏…」始终保留，避免用户搜不到时卡死。
- 空结果给「没有匹配「xxx」的文件夹」并保留新建入口。
- 窗口高度常量同步加 `BF_SEARCH_H = 34`（28px 输入框 + 6px 间距），与 CSS 契约一致。

### 2.3 块级差分更新（本次最有含金量的一项）

此前是「整包 113MB 全量下载 + 断点续传」。现在：

- **发版侧**：`make-release` 把安装包按 512KB 切块、逐块算 sha256，生成 `Nyx-Setup-<v>.blocks.json`（1.6.0 = 227 块 / 16.5KB），与安装包一起写入更新源与留档；`latest.json` 增加可选字段 `blocks`（旧版不认也不坏）。
- **下载侧**：`updater` 仅在远端源尝试差分——
  1. 找基线：扫描 `updates-archive\<x.y.z>`，取版本号最大且不等于目标的那份安装包；
  2. 建索引：基线按同样 512KB 切块算 sha256，得「块 hash → 偏移」；
  3. 重建：遍历目标 blocks，命中就用基线字节，未命中用 `Range` 拉该块（必须是 206），顺序写 `.part`；
  4. 整体校验 sha256，通过才算成功。
- **任何异常都静默降级整包**：blocks 缺失 / 基线缺失 / 服务端不支持 Range / 块长度不符 / 最终 sha 不符。
- 演练（真实 1.5.0，基线只改 3 处字节）：**224/227 块命中（98.68%），实际只传 1.2MB / 3 次 Range**；三种降级路径全部实测通过（404、200、sha 不符）。
- **诚实的预期管理**：发行包是 LZMA 固实压缩流，代码一改几乎整条流都变，真实跨版本命中率会远低于 98.68%。差分是「有则省点」，不是"常态省一半"。基线依赖留档（`--prune` 默认保 3 版）。

### 2.4 历史按站点分组

- 历史页签顶部加「按时间 / 按站点」视图胶囊（复用 `.tb-chip`）。
- 按站点：图标 + 域名 + `N 次访问 · 相对时间`（刚刚 / 12 分钟前 / 3 小时前 / 5 天前）；点行就地展开该站点明细（最近 50 条，超出给一行说明），再点收起；支持键盘（Enter / 空格 + `aria-expanded`）。
- 站点按最近访问倒序、明细按访问时间倒序；搜索先过滤再聚合，两种视图都生效；视图选择记忆在 `localStorage['nyx:tb:history-view']`。

### 2.5 站点图标缓存共享

- 把 1.5.0 写在 `main.js` 里的抓取/缓存逻辑抽成 `src/core/site-icons.js`：缓存目录统一为 `<userData>/site-icons/`（原来是 `suggest-icons`），地址栏建议与工具箱共用，不重复抓、不重复存。
- 新 IPC `nyx:icons:get {host}` → `{ ok, icon }`：命中缓存直接返回 data URL，未命中返回空串并在后台抓，抓到后向**所有窗口**广播 `nyx:icons:ready`；调用方只负责补画。
- 工具箱聚合行先画首字母色块（与建议一致的哈希取色），拿到真图标后只替换该行图标槽，不整表重渲染、不打断展开状态。

## 五、已知边界

1. 安装版仍为 1.2.9，本次只构建发布，未强装。
2. 差分命中率取决于"和基线有多像"：真实版本间命中率远低于演练值；基线被 `--prune` 清掉、或更新源不支持 Range，都会退回整包。
3. 差分只在远端源启用；本地目录源继续走整包复制（本地复制没有流量概念）。
4. 图标缓存目录从 `suggest-icons` 改名为 `site-icons`（旧目录不再读取，属一次性迁移；不影响功能，只是旧图要重抓一次）。
5. 工具箱每轮最多补 60 个站点图标，极久远的站点会一直显示首字母色块。
