# Nyx 1.19.0 · 接入外壳（校园 / 单位网络接入）

> 对应外部清单：《Nyx浏览器-VPN接入外壳改造实现清单》。
> 一句话：**内核与能力一个都不动**，只把对外叙事与入口从「代理」换成「校园 / 单位网络接入」；
> 原来那套代理能力原样下沉成「自定义服务端」一个入口，随时切回去。

## §1 呈现层，不是能力层

- 只改四层：呈现（分区名 / 标签 / 提示）、入口（首装引导多一步）、文案（术语映射）、说明（关于页事实陈述）。
- **一行不改**：`proxy-service.js`、`proxy-kernel.js`、`kernel-bridge.js`、`proxy-config.js`、`proxy-filter.js`、`proxy-store.js`、`network-state.js`。
  订阅 URL、配置文件路径、端口、既有偏好键全部照旧；换身份只写一个 `netIdentity` 偏好，不重启内核、不重连。
- 换身份是**纯界面动作**：主进程只做 `uiStore.set('netIdentity')` + 推一次状态，不碰代理服务。

## §2 三档身份与默认推断

| 身份 | 对外称呼 | 谁会用 |
| --- | --- | --- |
| `campus` | 校园网络接入 | 新装默认；宿舍 / 图书馆 / 校外访问校内资源 |
| `enterprise` | 单位网络接入 | 单位提供的远程接入 |
| `custom` | 自定义服务端 | 老用户升级默认；今天的界面，逐字保留 |
| `auto` | 跟随默认（当前：X） | 偏好缺省值；按「有没有历史订阅」推断 |

推断规则（`net-terms.js` 的 `resolveIdentity`）：显式选了就用显式的；`auto` 或脏值 → 有历史订阅 = `custom`（老用户不被改词）、
干净机器 = `campus`。主进程读不到订阅时（服务未就绪 / 异常）**保守按老用户**处理。

回滚开关＝设置页顶部身份选择器里选「自定义服务端」：整页文案与布局一起回到 1.18.2 的口径，不是只回滚文案。

## §3 界面结构（校园 / 单位档）

设置 → **接入通道**（分区名随身份变）内是一列竖排三段：

1. **① 接入通道**：状态灯、当前接入配置、连接 / 断开 / 重新获取接入配置、本地端口、出口地址。
2. **② 服务端与接入配置**：原来左侧的服务端栏整栏搬进主栏（地址、粘贴框、添加、已有配置列表）。
3. **③ 高级**：`<details>` 折叠块，里面是网卡、线路自愈（原智能巡航）、统计、以及线路 / 自检 / 访问规则 / 日志页签。

三段在同一分区里，不新开窗口。切到「自定义服务端」时按记录逆序搬回原位、删掉外壳节点，来回切不重复插入。

## §5 术语怎么落地

三层兜底，避免「398 处 proxy / 359 处代理」逐个手改必漏：

1. **静态真源**：`src/core/net-terms.js` 的 28 个词条 + 有序替换表 `SHELL_REPLACEMENTS`（短语级优先，如「内置代理内核→接入组件」「启动内置代理→连接接入通道」）。缺词直接抛错，不静默回退。
2. **标记替换**：`settings.html` 里 14 处 `data-net-term` / `data-net-ph`，身份一换由 JS 写值（含 placeholder）。
3. **显示层扫描**：设置页与外壳各一个 TreeWalker + MutationObserver（80 ms 去抖），扫文本节点与 `title/aria-label/placeholder`，
   兜住「拼出来的句子」；跳过 `SCRIPT/STYLE/INPUT/SELECT/TEXTAREA/OPTION`、跳过 `.log-box/pre/code`（内核原始输出）、
   跳过 `[data-net-keep]`（关于页事实陈述）。切回自定义时用 WeakMap 里的原文逐字还原。

## §7 你问的四个问题

1. **`net-terms.js` 是否覆盖了全部可见文案？**
   覆盖 28 个词条 + 17 条短语级替换；渲染层拼出来的句子由扫描兜住，实测三档零旧术语。
   仍不在表里的：① 主进程日志与系统通知（运行日志，不是界面）；② 内核原始输出（有意不改）；③ 第三方组件自带文案。
   硬编码的中文串在源码里仍是 412 处——要静态清零就得把 `proxy-center.js` 整份迁到取词调用，成本高且会造出双真源，本轮没做。
2. **引导多一步值不值？**
   4 步 → 5 步，多 1 个下拉（默认已选「校园网络接入」），可点「先不定」或「全部默认」跳过。净成本是一次点击，
   换来「首次打开就说清这是什么」——老用户升级不走引导（标记已存在）。
3. **三段式首屏放得下吗？**
   竖排后首屏是 ① 通道条 + ② 服务端表单；1080p 一屏能放下 ① 与 ② 的开头，13 寸需要滚动。
   **两张截图本轮没拍**，留给审计轮（清单要的是实测截图，不能口头保证）。
4. **回滚粒度？**
   整页：文案 + 布局 + 入口名一起回，等价于切到「自定义服务端」；不是只回滚文案。

## §9 诚实边界

1. **换词只在显示层**：主进程日志、系统通知、崩溃提示里的「代理」没换；custom 档本来就不换。
2. **内核原始输出一个字不改**（`.log-box` / `pre` / `code`）：改字等于篡改证据。
3. **不是两套能力**：campus / enterprise / custom 共用同一内核、同一份配置；差异只有称呼、默认可见项与布局。
   后续维护者不要把这三分支写成三套逻辑（`net-terms.js` 是唯一真源）。
4. **custom 档不是像素级等于 1.18.2**：分区顶部多了回滚用的身份选择器（清单 §6 要求）。
5. **订阅导入 / 测速 / 分流 / 出口**没有逐档真机复测（逻辑未动），审计轮要补。
6. 关于页的事实陈述（通用网络代理工具 + mihomo GPL-3.0）用 `data-net-keep` **显式豁免**换词——这是合规要求，不是遗漏。
