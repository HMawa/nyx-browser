            接入模式
            
                —
              
            
              
            
                
            
                  内置模式里 agent 只能走 Nyx 自己的接口，每个动作都过统一通道；外部接入会让别的程序直接驱动浏览器，
                  那边做什么 Nyx 看不见，审计只剩「经过浏览器的部分」。

              页面摘要
              
                —
              
              
              
              
                
              
                  摘要只从页面原文里抽取句子，不调用任何生成式接口；每句话都能在页面上找到出处。
                  它把网络请求里失败的数量一起给出来——页面显示成功、接口其实 500 是最容易被骗的地方。
                
              
                
              
                  
                
              
                
              
              
              
            
              

            
              
              
              
                
              让 agent 改设置
              
                —
              
              
              
              
                
              
                  外部 agent 可以通过本地接口改一小部分设置，每次都要你在确认框里点一次，
                  改了什么会写进下面的「动作留痕」。这个接口改不了隐私与安全相关的键——
                  那些只能在设置里由你自己改。
                
              
                
              
                  
              
                    
              agent 能改（要确认才生效）
              
                    
                
                  
                
                  
                
                    
                agent 连问都不许改
                
                    
                  
                  
                  
                
                  
                
                  
                  这个接口只改本机上 Nyx 的偏好设置，每次修改都会写进 agent 动作留痕。
                
                  
                
                  
                  场景预设：agent 可以一次套用一组设置，但里面每一项要确认的改动都得逐项确认，
                  少一项就整组不动。
                
                  
                
                    
                
                    
                
                    撤销：还没有哪个 agent 改过设置，暂时没有可撤销的。
                    
                
                    
              
                    
            
                    

            
                    
              
                    
                
                    紧急停止
                    
                —
              
                    
              
                    
                
                    
                  急停会中断正在执行的动作，并拒绝之后所有新动作，直到你手动恢复。已发出的单条脚本无法在浏览器内核里中途掐断，
                  所以最坏情况是那一条跑完，但不会再有下一条。
                
                    
                
                    
                  
                  
                
                    
                
                    
              
                    
            
                    

            
                    
              
                    
                
                    动作留痕
                    
                —
              
                    
              
                    
                
                    
                  记录时间、站点、动作、判定（放行 / 人工确认 / 拒绝）、结果与耗时。输入内容与地址里的查询串已脱敏。
